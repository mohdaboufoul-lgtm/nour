# Nour — Module briefs (phase 0)

One brief per build module in `docs/DESIGN.md` §8. Hand an engineer this file plus `DESIGN.md`; the signatures they must implement are in DESIGN §3 (the subsection named below), the columns in §5, the tests they own in §7/§8. Common rules for every module: import only modules from earlier waves (siblings never import each other — `tests/unit/test_wave_imports.py` fails your build otherwise); every side-effecting port method takes a `PortCall`; every text you write into a prompt, memory, audit, outbound message or handoff is a `SafeStr` from `LeakGuard`; every timestamp comes from the `Clock`, every id from the `IdGenerator`; docstrings name the SPEC section they enforce; `ruff`, `mypy` and your own tests green before hand-off.
